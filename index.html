CART Binary Decision Tree — Greedy Recursive Partitioning

The tree grows one node per step (breadth-first). At each node the algorithm scans every candidate threshold on both features, scores each split by impurity decrease ΔI = I(parent) − (n_L/n)·I(L) − (n_R/n)·I(R), and keeps the best one. A node becomes a leaf when it is pure, too small, too deep, or when no split gains enough. The loss shown is the sample-weighted impurity of all current leaves, which decreases monotonically as the tree grows.
